RESOLVE & MEASURE

Read the fact that matters.

Rastgo reads host-registered sources. Measures return a scalar value or keyed groups; checks and their measures run sequentially. Credentials and query-only access belong to the host.

Architecture context

The host registers sources, supplies trusted checks and selects a result sink. Each measure resolves an exact source name; qualified names do not fall back to another connection.

Hawta records ingestion facts. Rastgo can read published facts and judge them against an explicit policy. Publication freshness limits what those facts reveal.

Source errors become Error results before severity applies. Critical policy breaches Fail; warning and info breaches Warn.

The JSONL sink and dashboard reader are separate components. Use unique run IDs and preserve per-domain freshness when combining histories.
