Theming

The package ships no themes and there is nothing to configure. Fields arrive with a plain default look — a label above, a bordered box, a red error message — and everything past that is one stylesheet you write, targeting the form with ::part().

Structure JSON

One file decides which fields exist, which are required, and where the ticket goes. The root is a node — data sits beside tag and children, not above them.

Always write a data object, with a requestUrl in it

In the currently published build a structure with no data throws on load and the form never appears. That is fixed in the next release, after which it renders normally and instead fails at submit with “Request endpoint is not configured” when requestUrl is missing. Write both and neither version can bite you.
