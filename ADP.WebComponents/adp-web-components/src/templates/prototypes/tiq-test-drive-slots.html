Test drive booking · day strip vs date picker

Pick a branch once, then compare the two ways of choosing a slot on the last row. Option A is the day strip: days and times stacked, both visible at once. Option B is the date picker: a month calendar that slides across to that day's times, one decision per screen. Same endpoint, same response, same submitted value — only the interface differs.

Submit is disabled on purpose — requestUrl points at example.invalid, so this page cannot create a real test-drive ticket. Friday, Saturday and every third day are blocked by a demo rule so the disabled-day state is visible; the live calendar has no such rule.
