About this page

What was fitted to the vehicle after it left the factory: one row per part, with its number, description and drawing, and the job, invoice and installing company that fitted it. The head carries the total, and a long list opens on its first ten rows behind a Show all control.

Each fixture chip says which state it reaches. The main cases live in the broker-market environment, which the page opens on; the edge cases — a picture the drawings do not cover, long text, a missing job and invoice, an installing company the environment cannot name — are in edge-cases, one switch of the Environment control in the rail away.

The page starts on Show all so all six columns are visible; Host default puts back the three columns (job, invoice, company) a host hides unless it says otherwise.

Failed pictures is a showcase-only simulation of the failed-picture case: the generated data cannot produce a dead picture, so this switch reloads the current vehicle with every accessory's picture pointing at an address that does not exist. The component is not changed by it.
