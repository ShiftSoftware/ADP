adp-web-components · vehicle lookup

About this page

The shell that holds all eight vehicle components and shows one at a time. The VIN field and the tab strip above belong to the host — a page embedding this component has to build them, and they are what drive fetchVin() and active-element. This page sets ssc-query-string, so a search from any tab but SSC leaves the SSC tab saying the campaign check was not run, with a button to run it — the way a host that only logs SSC lookups is wired.
