About this page

The build record for a VIN: what the vehicle is in the head, and the codes those words were resolved from below it. The details band under the identity grid is the reader's — it opens expanded and folds away on the chevron, and that choice survives the next lookup.

The paint chip beside an exterior colour code comes from a bundled reference table, never from the response — there is no colour in the data, only a code. The name the distributor resolved always wins over the table's; the table is the only source of the chip, and a code it does not carry is shown as the code alone rather than guessed at. The chip is approximate and for identification only, which is what its tooltip says.

Each fixture chip says which state it reaches. Empty clears the panel back to idle and Error raises one on a settled card — the edge that has to go through the head's leave. Switch the Environment control in the rail to reach the fixtures from another environment.

This page deliberately consumes the component the way a Blazor host does — through setBlazorRef and callbacks named as attribute strings — rather than by assigning functions to the props.
