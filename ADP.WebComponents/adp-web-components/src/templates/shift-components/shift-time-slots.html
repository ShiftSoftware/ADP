Time slots

Overview

shift-time-slots shows one day's times as a grid and gives back the one chosen through timeChange. The host passes the times in; it makes no requests of its own.

Use it for

  • Choosing a time on a day already chosen: a booking, an appointment, a call back.
  • Beside a calendar or a day strip, as the second half of a slot picker.

Not for

  • Free time entry or durations.
  • Times on several days at once.
  • Five appearances (vanilla, material, soft, sharp, minimal), five sizes (xs to xl, md by default) and light or dark. Try them in the Playground.
  • language (en, ar, ku, ru) sets the direction, the digits and the AM and PM words.

Installation

From npm or a CDN, then place the tag.

npm

Install the package, then import the element once. The import registers <shift-time-slots>.

CDN

The whole package in one module tag, or this element alone through the host loader. Pin the version you tested; one page loads one version.

The tag

Attributes for plain values, properties for arrays. Listen for timeChange.

Times & values

What goes in, what comes out, and what the grid does when it changes.

Time strings

Times go in and out as HH:mm on a 24-hour clock, with no date or time zone. hourCycle changes only the labels. Duplicates are merged, the list is sorted, and anything that is not a time is ignored.

Choosing

  • A click, Enter or Space chooses a time and fires timeChange, even for the time already chosen.
  • disabledTimes and disabled block choosing. A value not in times chooses nothing.
  • Setting value from the host fires nothing.

Changing the times

New times fade the old grid out and rise in one after another, while the height moves to the new number of rows. loading shows skeletonCount placeholders of the same size; an empty list shows emptyText. See example 4.

Keyboard & accessibility

A radio group with one tab stop, moved like a grid.

Keys

Key Does
← → Previous or next open time (mirrored in RTL)
↑ ↓ The open time above or below, by as many columns as fit
Home End First or last open time
Enter Space Choose the focused time
Tab Into and out of the grid; the grid is one tab stop, on the chosen time or the first open one

Screen readers and contrast

  • The grid is a role="radiogroup" of role="radio" buttons with aria-checked. Unlike the WAI-ARIA radio group, arrows move focus without choosing, so moving through the day never books a time; Enter or Space chooses.
  • Disabled times stay in the grid with aria-disabled, so a screen reader still reads them; arrows pass over them.
  • While loading the group carries aria-busy; the count of times, the loading text or the empty text is announced politely.
  • Every appearance meets WCAG AA for text and 3:1 for focus rings and the chosen time, in light and dark. Motion is instant under reduced motion.
