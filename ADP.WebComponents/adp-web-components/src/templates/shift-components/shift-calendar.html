Accessibility on a foreign input

  • shift-popover never sets or changes the anchor’s role. It adds aria-haspopup="dialog", and aria-controls when the anchor is in the page’s own tree; aria-expanded only where the anchor’s role allows it (a button or a combobox).
  • The dialog is named by label, else by the anchor’s own name through aria-labelledby, else “Pop-up” in its language.
  • An input that manages its own ARIA, like a MudBlazor field, keeps it; shift-input’s date input is itself a combobox.
