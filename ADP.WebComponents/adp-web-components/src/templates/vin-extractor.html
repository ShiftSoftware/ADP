About this page

Nine configurations of the same scanner side by side, because what it does depends almost entirely on which flags are set. The first five open a camera; the last four take a file instead. A device camera is needed for the first group.

Theming and API

Style it with the --shift-vin-extractor-* variables (it reads none of the shared --shift-* ones) and the ::part names below; language and color-scheme are opt-in, as are the label props and permissions-fallback. With none of them set it renders exactly as before. To replace an icon, give the element a child with slot="close-icon", slot="switch-camera-icon" or slot="capture-icon" and style it with the page’s own CSS.
