This example brings dealer views, file feeds, app tables and document sources into one ingestion flow. Hawta schedules each source and limits parallel fetching to keep the work bounded.

Architecture context

This example shows sources feeding lookups, reports and analytics. Source tables preserve what each system said; host-defined serving projections shape data for consumers.

Snapshot reconciliation uses a set-based diff and merge. File feeds can skip repeated reads when their metadata matches the last successful stamp.

Cosmos and versioned Parquet are two outputs from the same snapshot, each with its own schedule. The publisher commits files in its output directory; the host configures delivery to other storage and readers.

App-owned records retain their existing Cosmos replication. Each data family has one writer.

The source families, ownership boundary and consumer labels shown here are illustrative. Source activation, mappings and cadences depend on host configuration. Explore inside provides public code evidence and detailed mechanisms.
