# ADP (Auto Distributor Platform)

An open-source platform for automotive distributors, created and maintained by Shift Software. It is a set of .NET packages (`ShiftSoftware.ADP.*`) and web components (`adp-web-components`) built on the Shift Framework.

Documentation: https://adp-docs.shift.software
