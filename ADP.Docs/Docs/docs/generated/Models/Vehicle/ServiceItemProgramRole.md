Identifies the semantic role of a catalog service item within a service program.
 This classification is orthogonal to whether an evaluated item is free or paid.

| Value | Summary |
|-------|---------|
| ScheduledService | A normal scheduled-service item that may contribute to the base schedule cap. |
| Reward | A reward item that keeps normal free-item lifecycle behavior without defining the base schedule cap. |
