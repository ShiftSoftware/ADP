What produced a menu line. Mirrors the generator's own `MenuLineType`, so the distinction
 between an individually-sold item and a folded item group survives into the lookup — the older
 "is standalone" flag lost it.

| Value | Summary |
|-------|---------|
| Periodic | A scheduled service at one interval. |
| StandaloneUngrouped | A standalone item sold on its own. |
| StandaloneGrouped | A standalone group, folded from every item in it. |
