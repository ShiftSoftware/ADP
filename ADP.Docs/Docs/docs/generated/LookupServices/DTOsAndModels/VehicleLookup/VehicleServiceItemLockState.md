The states an item can be shown in without being claimable.

| Value | Summary |
|-------|---------|
| Locked | Not earned yet, and still earnable. Shown from the first lookup, so a customer can see what returning for their services is worth before they have had any. |
| Missed | Was earnable and no longer is. Told rather than hidden, because an item that quietly vanishes is exactly the confusion these states exist to remove. |
