A host-resolved classification. Only Code is eligibility evidence; Label is display text.

| Property | Summary |
|----------|---------|
| Code <div><strong>``string``</strong></div> | The host's stable code. Item conditions and reports match on this value. |
| Label <div><strong>``string``</strong></div> | Display text in the request's language. Never a rule key. |
| AsOf <div><strong>``DateTimeOffset?``</strong></div> | When the evidence behind the classification was measured, if the host states it. |
