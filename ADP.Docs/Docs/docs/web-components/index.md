# Web Components

`adp-web-components` is the npm package of custom elements that render ADP vehicle, part and
service data on any page — no framework, no build step. The package documents itself at
**[adp.shift.software](https://adp.shift.software/)**, built from each release, so demos and
API are always the ones that ship.
